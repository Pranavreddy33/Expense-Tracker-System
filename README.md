Expense Tracker System

About

A Java-based Expense Tracker System using MySQL and JDBC to manage daily expenses.

Features

- Add Expense
- Display Expenses by Month
- Category-wise Totals
- Update Expense
- Delete Expense

Technologies Used

- Java
- MySQL
- JDBC
- Visual Studio Code

Database Setup

1. Open MySQL Workbench or the MySQL command-line client.
2. Run the SQL commands from "database.sql".
3. Update the database username and password in "ExpenseTracker.java" or configure the required environment variable.

How to Run

Compile:
"javac -cp ".;mysql-connector-j-26.10.0.jar" ExpenseTracker.java"

Run:
"java -cp ".;mysql-connector-j-26.10.0.jar" ExpenseTracker"
